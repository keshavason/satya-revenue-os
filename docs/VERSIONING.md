# Versioning

The project uses Semantic Versioning for code and independent semantic versions
for skill, adapter, schema, fixture, and scorer packages.

- patch: compatible corrections with unchanged public contract;
- minor: compatible capabilities or optional fields;
- major: incompatible contract or behavior change;
- prerelease: evaluation candidate without stability or publication claim.

Benchmark comparisons record every relevant component version. A repository
version alone is insufficient when models, policies, fixtures, or scorers differ.
