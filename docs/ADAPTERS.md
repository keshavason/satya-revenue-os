# Vertical adapters

Adapters configure a horizontal core; they do not fork it. Each `adapter.json`
declares business model, primary units, lifecycle/funnel, metrics, acquisition
channels, constraints, compliance considerations, economic defaults, required
evidence, and unsupported assumptions.

RC1 includes SaaS, ecommerce, professional services, local business,
hospitality, and industrial B2B. Defaults are hypotheses, not facts. Core claim,
policy, provenance, approval, and release rules cannot be overridden by an
adapter.

Add a realistic fixture, negative validation case, and cross-industry plan
comparison for any new adapter.
